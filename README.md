# Samson Debebe — Video Editor & Motion Designer Portfolio

A cinematic, editorial web portfolio built with React and Vite for **Samson Debebe**, freelance video editor and motion designer based in Addis Ababa, Ethiopia.

## Features

- **Cinematic Showreel & Video Lightbox**: Full-fidelity video playback with custom modal viewer supporting both 16:9 widescreen and 9:16 vertical short-form reels.
- **Short-Form & Motion Graphics Split**: Dedicated showcases for high-retention vertical reels and landscape motion design work.
- **Interactive Color Grading Lab**: Real-time split-screen comparison slider demonstrating flat Log RAW camera footage vs. ACES graded color profiles (Kodak 2383, Cyberpunk Neon, and Monochrome Noir).
- **Brand-Authentic Software Toolkit**: Visual showcase of Premiere Pro, After Effects, DaVinci Resolve, and CapCut Pro with native brand identities.
- **Light & Dark Mode**: Persistent theme switcher with custom CSS custom properties.
- **Responsive & Motion-Enhanced**: Smooth scroll-triggered reveals, ambient desktop cursor glow, and 35mm film grain overlay.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Modern CSS with CSS Custom Properties (Theme tokens)
- **Deployment**: Vercel ready (`vercel.json` included)

## Getting Started

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```
